-- references/stores.md · format-feature
   * A screen needs no container around it: "Play feature graphic" (format-feature) around "Centre" (format-feature-centre). The canvas already writes a top-level frame's name above it, so the container is a box around the work, and a caption on it shows the name twice. Unless the user asked for a board or a background behind the screen, move the frame inside to the top level at the container's place (a move without `parent`), give it the container's name and theme, and delete the container.

-- references/stores.md · format-shot
   * Layers that don't fit where their frame's layout puts them: "List" (format-shot-list) sticks out of "Screen" (format-shot-screen) by 231. Give them "fill_container" or a smaller size, let the text wrap (textGrowth "fixed-width"), or give the frame a gap that isn't negative.
   * Loose ends: the last row of "List" (format-shot-list) ("Row" (format-shot-row-10)) has a line under it with no row below: lines go between rows, so take the stroke off the last one.
